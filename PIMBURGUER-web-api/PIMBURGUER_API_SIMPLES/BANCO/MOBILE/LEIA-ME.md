# Banco exclusivo do aplicativo

Backup inicial PostgreSQL 18.6: sete produtos, sete migrations, sem usuários, sessões ou pedidos do site. A API cria o administrador de desenvolvimento ao iniciar.

Use o arquivo .backup ou o arquivo .sql em um banco vazio. As instruções estão em ../../INTEGRACAO_APP.md. O manifesto registra as contagens e os hashes dos arquivos.
