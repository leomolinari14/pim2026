# Sistema web

- `index.html`: estrutura das telas.
- `css/`: estilos.
- `js/`: comportamento e comunicação com a API.
- `imagens/`: imagens do site e produtos iniciais.
- `Uploads/`: imagens de produtos cadastradas.
- `vendor/`: bibliotecas usadas pelo site.

Inicie a API pelo comando descrito em `../API/LEIA-ME.md` e acesse http://localhost:5181. Também é possível servir esta pasta com Live Server ou outro servidor web local; `js/config.js` aponta para a API em http://localhost:5181. Ajuste essa URL se mudar a porta.

O PostgreSQL precisa estar iniciado e o banco restaurado. Não há launcher nesta versão.
